# Regras do Projeto (GTA 2 Clone)

## Uso Obrigatório do `context.md`

1. **No Planejamento e Antes de Implementar:**
   - Sempre leia e leve em consideração o arquivo [context.md](./context.md) na raiz do projeto antes de planejar (`/plan`) ou escrever qualquer código.
   - Todas as decisões de arquitetura, física, desacoplamento, Input System e convenções de código C# descritas no `context.md` devem ser seguidas rigorosamente.

2. **Após Implementar:**
   - Sempre atualize o arquivo [context.md](./context.md) ao concluir uma implementação para refletir novos scripts, sistemas, componentes, estrutura de pastas ou mudanças arquiteturais.
